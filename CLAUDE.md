# Claude Code Einstieg

Bitte zuerst `HANDOFF_CLAUDE_CODE.md` vollständig lesen. Dort stehen Projektziel, Architektur, Nutzerregeln, bekannte Risiken, Roadmap und der empfohlene nächste Arbeitsblock.

Kurzregeln:

- Nicht deployen. Deploy macht der Nutzer.
- Kein `npm run build` ohne explizite Freigabe.
- UTF-8 mit echten Umlauten verwenden.
- Atomic Design einhalten.
- Dateien möglichst unter 500 Zeilen halten.
- Keine parallelen Button-/Card-/Modal-Systeme bauen.
- Worktree ist dirty: nichts ungefragt revertieren oder löschen.
- Größere, zusammenhängende Arbeitspakete bevorzugen und danach knapp berichten.

Nächster sinnvoller Startpunkt: Adminbereich mobil prüfen und glätten.
